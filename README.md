# 🍉 Fruit Ninja - Computer Vision (AI Gesture Control)

A complete **Fruit Ninja** game controlled by your finger in front of your camera using **Computer Vision & MediaPipe Hand Tracking**!

---

## 🎮 How to Play

1. **Camera Setup**: Stand or sit in front of your webcam in good lighting.
2. **Control**: Raise your hand and point your **Index Finger** towards the camera.
3. **Blade Slash**: Swipe your finger quickly across fruits on the screen to slice them!
4. **Combos**: Slice 2 or more fruits in a single quick stroke to get **COMBO BONUS** points!
5. **Avoid Bombs**: Slicing a black Bomb will explode and end your game!
6. **3 Lives**: Don't let normal fruits fall off the screen unsliced, or you lose a life (heart).

---

## 🚀 Option 1: Run Python Version (Desktop)

### Quick Run:
Double click:
```bash
run_game.bat
```
Or run directly via terminal:
```bash
python fruit_ninja.py
```

### Controls:
- **Index Finger**: Slice fruits / Blade sword
- **[R]**: Restart game
- **[Q]** or **[ESC]**: Quit

---

## 🌐 Option 2: Run Web Version (Browser)

Simply double-click:
```
web_fruit_ninja.html
```
and open it in Google Chrome or Microsoft Edge. Allow camera permission, and you can play directly in full screen at 60 FPS!
